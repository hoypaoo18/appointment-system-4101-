Design a modern, professional, responsive web-based Executive Appointment System.

The system is designed primarily for an Executive Assistant/Secretary who manages appointments for an executive. The Executive has view-only access, while an Administrator manages user accounts and basic system configuration.

The primary purpose of the system is to centralize executive appointment records and allow the Executive Assistant to create, check availability, confirm, update, reschedule, cancel, search, monitor, and complete appointments.

DESIGN STYLE

Create a professional corporate administrative dashboard.

Visual direction:
- Modern enterprise SaaS dashboard
- Clean and minimal interface
- Professional executive-office aesthetic
- Spacious layout
- Clear visual hierarchy
- Desktop-first responsive design
- Also support tablet and mobile widths
- Use a neutral professional color palette
- Use one restrained primary accent color
- Avoid excessive gradients, decorations, illustrations, or unnecessary animations
- Use modern sans-serif typography
- Rounded cards with subtle borders and shadows
- Clear icons for actions
- Strong accessibility and readable contrast
- Status must be communicated using both icon and text, not color alone

- Email
- Phone

Availability behavior:
After selecting the executive, date, and time, check availability.

Display:
- Available
- Conflict

If the selected time conflicts with another active appointment, clearly show:
"Conflict: The selected executive already has an appointment during this time."

Do not allow the user to confirm a conflicting appointment.

Allow back-to-back appointments when one appointment ends exactly when another begins.

Before saving, show an appointment confirmation/review screen containing:
- Client

- End time

RESCHEDULE

Create a rescheduling workflow.

Show current appointment information.

Allow the user to select:
- New date
- New start time
- Duration/end time

Check availability again before saving.

Display available and conflicting time slots.

Show confirmation modal before saving.

After confirmation:
- Update the schedule
- Change status to Rescheduled
- Preserve the appointment history

ROLES AND PERMISSIONS

Executive Assistant:
- Full appointment management
- Create
- View
- Search
- Update
- Reschedule
- Cancel
- Complete
- Manage client information
- Check availability

Executive:
- View dashboard
- View schedule
- View appointment details
- No create/edit/reschedule/cancel/complete actions

Administrator:
- Manage authorized user accounts
- Manage roles
- Activate/deactivate users
- Basic configuration
- No appointment editing unless explicitly authorized

- Invalid email
- Invalid phone
- Past date
- Invalid time
- Invalid duration
- Schedule conflict
- Failed availability check
- Failed save
- Unauthorized action
- Appointment not found
- No search results
- Session expired

Use clear inline validation messages.

SECURITY

Protected pages require authentication.

Do not expose appointment records to unauthorized users.

Use confirmation dialogs for:
- Cancel
- Reschedule
- Complete

RESPONSIVE DESIGN

Create responsive layouts for:
- Desktop 1440px
- Tablet 768px
- Mobile 360px

Desktop should use sidebar navigation.

Mobile should use compact navigation or a mobile menu.

Tables should become responsive cards or controlled horizontal scrolling on small screens.

ACCESSIBILITY

- Clear form labels
- Keyboard-accessible controls
- Visible focus states
- Readable text
- Adequate contrast
- Do not use color as the only indicator of appointment status
- Buttons should have clear action labels
